# ADR-001: Android TV 与 Compose

Status: Accepted

原生Kotlin/Compose for TV；最低安装版本Android6.0/API23，compileSdk/targetSdk35。应用和所有Android库从版本目录读取统一版本。JVM模块使用JDK17，Android模块启用固定版本core library desugaring，供java.time等API在旧系统使用。

所有可安装版本均使用API23+ Keystore AES-GCM会话存储；设备密钥或安全存储不可用时明确失败，不回退明文。小米API28电视已完成先前正式包安装与登录验证，新版手机自适应及其他版本的实际范围见[兼容策略](../compatibility/android-tv.md)。

# ADR-004: 统一网络与代理

Status: Accepted — shared policy and unauthenticated proxy configuration implemented

所有X网页请求、连通性检测及未来Coil/Media3使用共享OkHttp网络策略。已实现显式直连/HTTP/SOCKS5、格式校验与本地保存，禁止重定向、自动重试和代理失败直连；用户手动触发诊断，不发送账号Cookie。真实HTTP代理与TV HTTPS检测通过，SOCKS5端到端、自定义DNS、代理认证和凭据加密尚待实现/验收。局域网扫码入站服务绑定私有IP，浏览器对电视同源提交，不经上游代理；出站X身份验证仍走共享代理配置。

# Screenshot privacy

These screenshots are captures of XView running on the tested devices. They are not demo data or mockups. Only the redacted PNG exports are committed.

- `phone-home.png`: phone portrait UI, captured on an Android virtual display without taking over the physical phone screen.
- `phone-settings.png`: phone settings with all visible account information covered.
- `tv-home.png`: Xiaomi MiTV-ANSP0, Android 9/API28, TV layout and D-pad focus.

All account names, handles, avatars, post bodies, thumbnails and other private content are replaced by opaque mosaic blocks. Mosaic cells are generated colors rather than a blur or downsample of source pixels. Layout, navigation and control positions are retained. Raw captures, UI trees, device addresses, account data and original media are not included.

Images in the root English and Chinese README files use `docs/assets/screenshots/...` relative paths.

# Roadmap

[产品设计](../design/xview-tv.md)、[登录决策](../adr/006-qr-cookie-login.md)和本页描述现行功能与待办。API23安装下限与设备覆盖见[兼容策略](../compatibility/android-tv.md)。

## 工程与应用壳

- [x] 九模块工程、版本目录、Convention Plugins、固定Wrapper与CI配置
- [x] 统一正式应用，无Demo/Prod变体；演示数据仅保留测试夹具，不进入APK
- [x] 首页上键显示唯一设置按钮，手机常驻设置入口；设置包含账号登录、代理、语言和播放偏好；子页→设置→首页返回
- [x] 中英文资源、系统/中文/英文切换、手机竖横屏与宽屏自适应布局
- [x] 本机ARM64编译、单测、Android Lint、APK；小米API28电视安装与ADB验收
- [ ] 远程仓库与实跑CI、Release签名及发布流程

## 网络与代理

- [x] 共享OkHttp，显式直连/无认证HTTP/SOCKS5，配置校验与私有持久化
- [x] 手动HTTPS检测、代理失败不直连、关闭重定向和自动重试
- [x] JVM真实HTTP代理转发/失败不回退测试，TV用户代理HTTPS实测成功
- [ ] SOCKS5端到端真实代理矩阵、认证代理及加密代理凭据、自定义DNS
- [x] Media3/图片共享代理策略和销毁清理；本机直连实测
- [ ] 运行时代理切换与SOCKS5媒体播放压力矩阵

## 账号登录

- [x] 电视局域网扫码网页与手机设置内直填完整Cookie，单框解析必需项，不自动读取浏览器，不用公网服务
- [x] TV随机端口/ID/RSA密钥、校验码、180秒、同源限制、单次密文消费、取消/后台关闭
- [x] node-forge局域网HTTP加密与标准WebCrypto互操作/篡改拒绝测试
- [x] 仅通过X网页`/home`会话ID与用户实体匹配验证身份，TV确认后才保存
- [x] API23+ AndroidKeyStore AES-GCM、冷启动恢复、重新验证、本地退出及清理
- [x] 真实TV二维码→网页填Cookie→密文提交→TV验证/确认→保存全链路；浏览器局域网权限提示
- [ ] API23/25 Keystore与低内存设备实测；不使用明文回退
- [ ] 完整过期/取消/并发重放/错误Cookie/已有账号切换/挑战及限流设备矩阵、安全审计
- [ ] 多账号与账号缓存隔离

## 媒体与Provider

- [x] X网页动态操作发现、正在关注媒体时间线、游标分页/去重、HTTP200 errors检测
- [x] 现代媒体优先Lazy网格、稳定key/contentType、可见帖子X/Grok自动翻译
- [x] 移除图片独立页面；开源Media3 PlayerView MP4/HLS、清晰度切换、倍速、标准进度条与快进退
- [x] 全站视频搜索、当前账号喜欢的视频、关注列表与博主视频；四类网页接口与游标本地实测
- [x] 本机虚拟屏媒体播放/翻页实测、TLS关闭主线程崩溃修复
- [ ] 单帖接口、多账号、事务标识完整生成与长期风控稳定性
- [x] 当前筛选队列上一/下一视频、硬解优先、右侧长按临时加速和双击快进退、独立秒数设置
- [ ] 播放历史、收藏、后台状态恢复和长时heap/GC泄漏压力测试
- [ ] Guest公开Provider许可与稳定性验证、本地订阅与链接导入

真实媒体使用当前账号网页数据，不把测试夹具当账户内容。仅本机虚拟屏已验证本轮媒体功能，电视包未更新。
